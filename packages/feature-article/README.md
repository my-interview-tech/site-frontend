# @my-interview/feature-article

Сервис отображения статьи.
Сервис сам загружает документ и показывает скелетон, ошибку или содержимое ответа.

Импорт только из `@my-interview/feature-article`. Слайсы пакета снаружи недоступны.

## Публичный API

- `ArticleView` — экран.
- `ArticleViewProps` — тип пропсов.
- `Article`, `ArticleRequest` — документ и ключ загрузки.
