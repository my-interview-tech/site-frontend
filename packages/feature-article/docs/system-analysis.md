# Системная аналитика

Пакет `@my-interview/feature-article` показывает контент одной статьи.
Поля документа описаны в [контракте](contract.md). Здесь поведение экрана.

## Границы

Пакет загружает документ по `id` и `tech` и рисует экран.

`useResponse` вызывает `useFetch(`${tech}:${id}`, () => loadArticle({ id, tech }))`.

## Состояния экрана

`ArticleView` выбирает экран по `getPageStatus`.

| Статус    | Условие                                         | Экран                                                        |
| --------- | ----------------------------------------------- | ------------------------------------------------------------ |
| `loading` | идёт запрос                                     | `Skeleton`                                                   |
| `error`   | запрос упал или в корне нет обязательных ключей | `Error`: «назад» вызывает `onBack`, повтор вызывает `reload` |
| `success` | загрузка прошла и ключи корня на месте          | `ArticleContent`                                             |

Обязательные ключи корня: `id`, `title`, `access`, `accordion`, `ad`, `content`, `meta`, `toc`, `tocLabel`.
