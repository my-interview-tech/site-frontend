# @my-interview/feature-articles-list

Экран технологии (`JavaScript`, `TypeScript`, `React` и т.д. ).
Сервис сам грузит данные и показывает скелетон, ошибку или содержимое.

Импорт только из `@my-interview/feature-articles-list`.

## Публичный API

| Экспорт               | Назначение       |
| --------------------- | ---------------- |
| `TechnologyView`      | Экран технологии |
| `TechnologyViewProps` | Пропсы экрана    |
