# Системная аналитика

Пакет `@my-interview/feature-articles-list` показывает экран технологии.
Поля документа описаны в [контракте](contract.md). Здесь поведение экрана.

## Границы

Пакет загружает документ по `slug` и рисует экран.

## Состояния экрана

`TechnologyView` выбирает экран по `getPageStatus`.

| Статус    | Условие                                         | Экран                                                             |
| --------- | ----------------------------------------------- | ----------------------------------------------------------------- |
| `loading` | идёт запрос                                     | `Skeleton`                                                        |
| `error`   | запрос упал или в корне нет обязательных ключей | `ErrorState`: «назад» вызывает `onBack`, повтор вызывает `reload` |
| `success` | загрузка прошла и ключи корня на месте          | `TechnologyContent`                                               |

Обязательные ключи корня: `accordion`, `recommendations`, `resources`, `sections`, `slug`, `title`, `toc`, `tocLabel`.
