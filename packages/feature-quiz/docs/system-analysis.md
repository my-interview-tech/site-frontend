# Системная аналитика экрана квиза

Пакет `@my-interview/feature-quiz` показывает один квиз. Поля документа — в [контракте](contract.md). Здесь поведение экрана.

## Границы

Пакет загружает квиз по `id` и `tech` и рисует форму. Каталога квизов нет. Роут и крошки — у хоста.

Оплата и запись «тема изучена» в список технологии не входят. `onSolved` только сообщает хосту, что все ответы верные.

## Загрузка

`useResponse` вызывает `useFetch(`${tech}:${id}`, () => loadQuiz({ id, tech }))`.

Источник сейчас мок `loadQuiz`. Ответ приходит через 400 мс.

- `id === 'error'` — запрос отклоняется;
- `react:4` и `nextjs:4` — квиз из трёх вопросов;
- другой ключ — короткий квиз из одного вопроса.

## Состояния экрана

`QuizView` выбирает экран по `getPageStatus`.

| Статус    | Условие                                         | Экран                                                                  |
| --------- | ----------------------------------------------- | ---------------------------------------------------------------------- |
| `loading` | идёт запрос                                     | `Skeleton`                                                             |
| `error`   | запрос упал или в корне нет обязательных ключей | `ErrorState`: «Назад» вызывает `onBack`, «Повторить» вызывает `reload` |
| `success` | ключи корня на месте                            | форма или итог                                                         |

## До старта

Форма по центру, справа колонка: «Что проверяет этот квиз» (`intro.checks`) и слот `ad`.

`retryAt` позже серверной даты — текст «Можно пройти снова через …». Кнопки старта нет. Остаток считается от `serverDate` на момент загрузки.

Иначе экран правил: `intro.rules` и «Начать квиз». Таймер ещё не идёт.

## Шаги

Одна форма на все шаги. Ответ хранится в поле `choice.id`. Ряд шагов — дорожка: текущий залит, открытый с обводкой, будущий серый.

- уже открытый шаг можно выбрать: с 19-го открывается 5-й. Ещё не открытый не нажимается;
- таймер справа — сумма `questionSeconds` по всем вопросам. Смена шага его не сбрасывает;
- общее время вышло — пустые ответы «Не ответил», сразу итог;
- «Дальше» проверяет только текущий видимый вопрос. Пустой ответ остаётся на шаге, подпись «Выберите ответ»;
- «Назад» есть, если шаг не первый и у `navBar` стоит `isStepBackAvailable`;
- последний шаг или `buttonAction === 'submit'` сдаёт форму.

Скрытый вопрос (`visibility: false`) шаг не блокирует.

## Итог

Итог не страница BDU. Статусы: «Верно», «Неверно», «Не ответил». Верный вариант не показывается.

«Тема сдана» и `onSolved` — только если пустых нет и все ответы верные. Иначе «Есть ошибки».
