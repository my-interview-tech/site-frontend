# Контракт дорожной карты

Отдельного документа загрузки нет. Экран не ходит за данными. Источник графа — `src/shared/config/graph.ts`. Публично наружу выходит только `Roadmap`.

## Пропсы

Хост передаёт в `Roadmap`:

- `topicHref` — `(slug: string) => string`. Куда вести с узла темы. Обязательный.

## Адрес

Трек берётся из query `track`. Открытые значения: `frontend`, `backend`. Треки `qa`, `analytic`, `devops` закрыты (`isClosed`): данные лежат в графе, в переключатель не попадают.

Нет параметра, значение неизвестно или трек закрыт — `frontend`, и адрес переписывается на `?track=frontend` через `replace`.

Смена трека пишет `?track=` через `replace`, без сброса скролла.

## Изученное

Ключ `localStorage`: `my-interview-profile`.

Читается поле `roadmaps`: массив строк-слагов. Битый JSON, нет ключа, поле не массив или хранилище недоступно — пустой набор. Изменение ключа в другой вкладке перечитывается по событию `storage`. Пакет это поле не записывает.
