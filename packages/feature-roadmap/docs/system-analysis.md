# Системная аналитика дорожной карты

Пакет `@my-interview/feature-roadmap` рисует граф одного трека. Пропсы и query — в [контракте](contract.md).

## Границы

Пакет не объявляет роут и не знает, НЗ это или АЗ. Хост открывает экран и передаёт `topicHref`.

Кабинет со списком карт пакета не касается: граф только читает `roadmaps` из того же ключа профиля.

## Трек

Сверху переключатель: Frontend, Backend. QA, System Analytic и DevOps закрыты и в переключатель не попадают. Активный пункт подсвечивает ползунок.

Смена трека сбрасывает текущий пункт оглавления. Граф пересобирается.

## Граф и оглавление

Узел темы — ссылка на `topicHref(slug)`. Выключенный узел — не ссылка.

Оглавление справа — заголовки шагов. Клик скроллит к якорю. Видимый якорь подсвечивается. Якорь — `roadmap-<slug>`.

Изученный слаг из `roadmaps` помечается на узле. Трек эту отметку не меняет.

## Мобильная версия

Ниже `desktopS` граф заменяется вертикальным списком шагов: развилка — заголовок с карточками веток, тема — карточка, заметка — плашка. Оглавления нет. Граф стоит по центру заголовка, оглавление — в правом поле и его не сдвигает.
