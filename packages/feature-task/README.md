# @my-interview/feature-task

Экран задачи: условие, редактор и консоль прогона.
Сервис сам грузит задачу и показывает скелетон, ошибку или рабочую область.

Импорт только из `@my-interview/feature-task`.

## Публичный API

| Экспорт         | Назначение      |
| --------------- | --------------- |
| `TaskView`      | Экран задачи    |
| `TaskViewProps` | Пропсы экрана   |
| `Task`          | Документ задачи |
| `TaskRequest`   | Ключ загрузки   |
