# Системная аналитика

Пакет `@my-interview/feature-task` показывает экран задачи.
Поля документа описаны в [контракте](contract.md). Здесь поведение экрана.

## Границы

Пакет загружает задачу по `id` и `tech`, рисует рабочую область и прогоняет решение в воркере.
Список задач и переход к нему — забота хоста и `@my-interview/feature-tasks-list`.

## Состояния экрана

`TaskView` выбирает экран по `getPageStatus`.

| Статус    | Условие                                         | Экран                                                             |
| --------- | ----------------------------------------------- | ----------------------------------------------------------------- |
| `loading` | идёт запрос                                     | `Skeleton`                                                        |
| `error`   | запрос упал или в корне нет обязательных ключей | `ErrorState`: «назад» вызывает `onBack`, повтор вызывает `reload` |
| `success` | загрузка прошла и ключи корня на месте          | `TaskWorkspace`                                                   |

Обязательные ключи корня: `hiddenCount`, `id`, `language`, `lead`, `starter`, `statement`, `tech`, `tests`, `title`.

## Попытка

- «Запустить» (`⌘↵` / `Ctrl+↵`) гоняет открытые тесты через `runTask`.
- «Сдать» (`⇧⌘↵` / `Ctrl+Shift+↵`) вызывает `submitTask`: открытые и скрытые тесты.
- Клавиши работают и в редакторе, и на панели. Кнопки несут `aria-keyshortcuts`.
- Пока идёт прогон, обе кнопки, клавиши и «Сбросить» заблокированы. Уход со страницы отменяет прогон: воркер завершается.
- «Сбросить» возвращает `starter`, удаляет черновик и активна, только если код изменён.
- Отметки у открытых тестов в условии и консоль читают один и тот же отчёт последнего прогона.
- Ошибка компиляции, исключение вне теста, падение и таймаут 2 с приходят как `report.error` и показываются в консоли.
- «Сдать» без единого падения ставит отметку «решено» в `localStorage` и вызывает `onSolved`. Разводящая видит отметку сразу, другие вкладки — по событию `storage`.

## Черновик

- Ключ `task-draft:v1:${tech}:${id}`, значение `{ code, updatedAt }`.
- Запись через 500 мс после последней правки, при `pagehide` и при уходе с экрана.
- Код, равный `starter`, не хранится. Битый черновик игнорируется.

## Раннер

- Решение компилирует sucrase в модуль CommonJS: `export` — в `exports`, `import` — в `require`. `require` пускает только `react`.
- Компиляция — один раз на прогон, модуль создаётся заново на каждый тест: состояние решения между кейсами не общее.
- Тесты идут по очереди. React-тесты рендерят в документ linkedom внутри воркера.
- В воркере закрыты `fetch`, `XMLHttpRequest`, `WebSocket`, `EventSource`, `Worker`, `importScripts`, `indexedDB`.
- Один воркер держится запасным. Он сообщает `ready` после загрузки, прогон забирает его и поднимает следующий. Таймаут 2 с считается от `ready`, загрузка — до 15 с.

## Ошибки в коде

- Синтаксис: отчёт несёт `errorKind: 'syntax'` и `errorAt` — строку и колонку с единицы. Редактор ставит отметку по первой ошибке разбора CodeMirror через 300 мс после ввода; если разбор ошибки не видит, место берётся из `errorAt`.
- Выполнение: место — первый кадр `solution.js` в стеке, переведённый в исходник картой sucrase. У ошибки уровня модуля позиция в `report.errorAt`, у ошибки в тесте — в `errorAt` кейса. Редактор подчёркивает слово под позицией.
- Провал `assert` позиции не ставит: это ошибка логики, а не места.
- Консоль пишет «Синтаксическая ошибка» или «Ошибка выполнения» и «Строка N, колонка M».
- Отметка прогона держится, пока код совпадает с отправленным.
- Ошибки типов TypeScript не проверяются.

## Редактор

- Tab принимает подсказку, если список открыт, иначе ставит отступ. Выйти из редактора с клавиатуры — Esc, затем Tab.
- Автодополнение: глобалы песочницы, `React` и сниппеты хуков для React, `hints` задачи.
- ESLint в отдельном воркере для JavaScript и React: предупреждения через 500 мс после ввода, исправление — действием в подсказке. Для React — правила хуков.
- Линии отступов подсвечивают активный блок, в том числе в сниппетах условия.

## Раскладка

- От планшета: условие слева, редактор и консоль справа, всё на высоту окна; панели скроллятся сами.
- Ниже планшета: вкладки «Условие», «Код», «Результат». Старт прогона открывает «Результат». Подсказки клавиш скрыты.
- Вкладки прячут панели стилями, а не размонтируют: код в редакторе не теряется.
