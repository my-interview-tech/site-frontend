# @my-interview/feature-tasks-list

Разводящая задач технологии: карточки и фильтры.
Сервис сам грузит список и показывает скелетон, ошибку или содержимое.

Импорт только из `@my-interview/feature-tasks-list`.

## Публичный API

| Экспорт          | Назначение      |
| ---------------- | --------------- |
| `TasksView`      | Экран списка    |
| `TasksViewProps` | Пропсы экрана   |
| `TasksScreen`    | Документ экрана |
| `TaskCard`       | Задача в списке |
| `TasksRequest`   | Ключ загрузки   |
